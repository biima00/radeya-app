# Changelog

All notable changes to Radeya will be documented in this file.
Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-06-20

### Added
- Dashboard multi-komoditas: broiler, petelur, penggemukan, susu, breeding ruminansia
- Daily record keeping dengan kalender
- FCR, SR, IP/EPEF calculation untuk broiler
- HDP, FCR untuk petelur
- ADG, bobot tracking untuk penggemukan & breeding
- Produksi susu per ekor tracking
- AI Veterinary chatbot (Gemini)
- Feed formulation engine (Pearson Square)
- Inventory management (pakan, obat, peralatan)
- Animal identity tracking (RFID/ear tag)
- Treatment & withdrawal period management
- Multi-tenant organization support
- Subscription billing (Midtrans)
- Google OAuth login
- JWT authentication with rate limiting
- Responsive glassmorphism UI
- Profit simulator on landing page
